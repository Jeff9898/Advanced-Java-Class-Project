# **Multithreaded Spring Application with Cloud Deployment**

## **Project Overview**
This project is a modified version of the Landon Hotel Scheduling Application. The goal was to enhance the back end with:
- **Multithreaded functionality** for displaying welcome messages in English and French.
- **Localization** for multiple currencies (USD, CAD, EUR).
- **Time zone conversion** for live presentation times.
- **Cloud deployment readiness** via Docker.

## **Features**
1. **Multithreading**:
   - Displays welcome messages in English and French using separate threads.
2. **Localization and Currency Support**:
   - Front-end modified to display reservation prices in USD, CAD, and EUR.
3. **Time Zone Conversion**:
   - Converts and displays presentation times in ET, MT, and UTC.
4. **Dockerization**:
   - The application is containerized using a custom Dockerfile.
5. **Cloud Deployment**:
   - Application is prepared for deployment to cloud platforms like AWS or GCP.

## **Technologies Used**
- **Java** (Spring Boot Framework)
- **Angular** (Pre-built front end)
- **MySQL** (Database)
- **Docker** (Containerization)
